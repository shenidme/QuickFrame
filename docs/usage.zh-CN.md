# QuickFrame MVP

双击 QuickFrame.exe 即可运行，无需安装。Windows 10/11，使用系统 .NET Framework。程序只在系统托盘运行，没有控制窗口；图标为青紫霓虹方框，可能位于任务栏的隐藏图标区域。

- 按住鼠标右键拖动，移动达到 8 像素后显示矩形框。
- 持续按住右键时，框和遮罩一直保留，鼠标静止也不会超时；只有松开右键后才开始停留时间和 0.5 秒消散倒计时。
- 默认预设为“夜城协议 · 2077”：黄黑切角装甲边框、电青副线、警示红状态条、扫描标签、沿边流动光点和刻度。开始画框时约 0.32 秒展开，四角从外侧收拢锁定；松开后默认停留 1.5 秒，最后 0.5 秒伴随两次边框闪断，角标和青红碎片向外散开，总计约 2 秒消失。小框会减少装饰。扫描标签是视觉装饰，不表示真实联网或扫描。支持连续画多个框，各自独立消散。
- 普通右键单击仍打开原软件的右键菜单。
- Ctrl+Alt+F8：暂停/恢复画框。双击托盘图标也可以暂停/恢复。
- 鼠标监听在独立线程运行，避免光效绘制卡顿导致监听超时。检测到鼠标移动但监听没有回调时会尝试重新连接；也可右键托盘 → “修复鼠标监听”。如果菜单显示“恢复画框”，说明当前处于暂停状态。
- 默认开启聚焦遮罩：框内保持原亮度，框外约 0.28 秒渐暗至 46% 黑色遮罩；最后随边框用 0.5 秒渐变恢复。多个框同时存在时，全部框内区域保持正常。右键托盘 → “聚焦遮罩 · 框外渐暗”可以关闭。遮罩穿透鼠标，不阻挡软件操作。
- 右键点击托盘图标 → 外观预设：风格和颜色已合并为同一组单选菜单，包括夜城协议 · 2077、赛博霓虹、彩虹辉光、经典彩虹（无辉光）、冰蓝极光、琥珀全息、薄荷流光，以及橙红、蓝、绿、黄、紫五种纯色辉光。
- 切换预设同时切换对应的光效和配色。已画出的框保持各自预设；展开和故障闪断仅用于夜城协议，其他预设保留平滑渐隐。
- 右键点击托盘图标还可以修改渐隐前停留时间（无停留/1/1.5/2/3 秒）、清除、暂停、退出。“无停留”表示松开右键立即开始 0.5 秒消散；按住期间仍持续显示。渐隐时长固定为额外的 0.5 秒。
- 外观预设、停留时间（包括无停留）、聚焦遮罩开关、暂停/开启状态会自动保存到程序旁的 settings.ini。修改时立即保存，正常退出时再次保存；下次启动恢复。程序目录需要可写；移动程序时请一起带上 settings.ini。没有开机自启动。
- 重复运行不会出现控制窗口，只通过托盘通知提示已运行。

右键拖动在开启期间专用于画框。需要软件原有的右键拖动或按住右键操作时，请先暂停。普通右键点击通过松开时回放实现，管理员窗口、游戏等特殊程序的兼容性需实机确认。框固定在屏幕坐标，不随页面滚动。多屏使用整个虚拟桌面坐标，混合缩放仍需实际验证。

源码仓库中的主文件为 src/QuickFrame.cs；在仓库根目录的 PowerShell 中运行 ./build.ps1 -Test -Package 即可构建。

检查：QuickFrame.exe --self-test 运行手势逻辑测试；--smoke-test 短暂显示测试框，检查挂钩安装、自动消失与退出。测试结果写入同目录 txt 文件。
