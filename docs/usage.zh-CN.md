# QuickFrame 0.2

需要 Windows 10/11 和 .NET Framework 4.8。解压到可写目录，保留 QuickFrame.exe.config，运行 QuickFrame.exe。程序仅驻留系统托盘，霓虹方框图标可能位于任务栏的隐藏图标区域。右键图标 → **设置与预览** 才会打开设置窗口。

## 默认操作

- 按住右键拖动，移动达到 8 像素后显示矩形框。
- 按住时一直显示，静止也不会超时。松开后立即开始 0.5 秒渐隐。
- 新安装默认：**彩虹辉光、无停留、不加遮罩、自启动关闭**。
- 普通右键单击在松开时回放，保留原软件的右键菜单。
- Esc 清除所有框并取消当前画框；没有框时不拦截 Esc。
- Ctrl+Alt+F8 或双击托盘图标：暂停／恢复。
- 重复运行只提示已运行。也可运行 `QuickFrame.exe --settings` 打开现有实例的设置面板。

## 设置与预览

面板中修改参数会先更新预览，点击“保存设置”才会应用并保存；“取消”或关闭窗口会放弃草稿。“恢复默认”也需要保存才会生效。关掉面板后程序继续驻留托盘。

| 设置 | 说明 |
| --- | --- |
| 外观预设 | 7 种动态风格和 5 种纯色，光效与配色合并选择 |
| 画框操作 | 右键、Alt+右键、后退侧键、前进侧键 |
| 松开后停留 | 0～3 秒；0 表示松开即渐隐，按住期间仍持续显示 |
| 渐隐时长 | 0.15～1.5 秒，默认 0.5 秒 |
| 粗细／辉光 | 边框 3～9 像素，辉光强度 0～150% |
| 色彩循环 | 3～20 秒；数值越大流动越慢 |
| 框外渐暗 | 默认关闭，可选 10～80% 遮罩深度 |
| 遮罩范围 | 所有显示器，或最近画框所在显示器（按矩形覆盖面积选择） |
| 排除应用 | 进程名，用分号分隔，如 `chrome.exe; game.exe`；排除应用中鼠标操作保持原样 |
| 登录时自动启动 | 默认关闭，只影响当前 Windows 用户，不需要管理员权限 |

夜城协议包含展开锁定、装甲角标、流动光点和闪断消散。经典彩虹没有辉光。扫描标签均为视觉装饰。已完成的框保留各自风格和消散时长；粗细、辉光和流动速度为全局设置。

开启遮罩后，框外约 0.28 秒渐暗。多个框同时存在时，较早消失的框内区域会逐渐恢复到其余框的背景暗度；重叠区域取更明亮的效果。全部框消失后遮罩完全恢复。边框和遮罩均穿透鼠标。

## 开机自启动与设置保存

托盘菜单 → **开机自启动**，或设置面板 → **登录 Windows 时自动启动**。开启后在当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中写入 `QuickFrame` 项；关闭则删除这一项。它在用户登录后启动，不是系统服务。自启动状态以当前程序路径对应的注册表项为准。

开启自启动前请把程序放到长期保留的位置；移动 EXE 后应从新位置重新启用自启动。删除软件前请先关闭自启动。

设置即时保存到程序旁的 `settings.ini`，正常退出时再次保存，原文件保留为 `settings.ini.bak`。升级会保留已有偏好，旧版配置缺少的字段使用新默认值。移动程序时一起带上配置文件。发布便携包不包含个人配置。

## 排错与限制

- 失效时先检查是否暂停、触发方式及排除列表，再使用“修复鼠标监听”。
- 输入监听独立于渲染线程；检测到回调异常时尝试修复，系统唤醒和显示器配置变化后会清框并重连监听。
- 排除列表约每 250ms 检查一次前台进程。快速切换应用后立即操作，可能尚未完成更新。
- 管理员窗口、游戏、远程桌面、多屏混合缩放仍需实机验证。程序不主动请求管理员权限。
- 框固定在屏幕坐标，不随网页或窗口滚动。同时最多保留 20 个框。
- 更改默认鼠标行为可能与应用手势冲突，可使用 Alt+右键或排除应用。

## 构建与检查

在源码仓库运行 `./build.ps1 -Test -Package` 构建并生成便携包。Windows 桌面环境可运行 `./build.ps1 -InteractiveTests`，检查监听状态机、独立冒烟实例、设置控件与预览；结果输出到 `bin/*-test.txt`。

程序化状态机及控件测试不等同于实体鼠标、多显示器或特定应用的兼容性测试。
